# Enquête UI utilisateurs (mai 2022)

## Page d'accueil

#### Questions de relance feedbacks globaux

* Que pensez-vous de la page d'accueil ?
* Quelle est la première chose que vous feriez ?
* Qu'aimeriez-vous voir en plus sur cette page d'accueil ? En moins ?
* Que pensez-vous des informations fournies sur cette page ?
* Comment pensez-vous que cela va vous aider ?

## Dashboard Porteur de projet

### Contexte

Nous proposons une refonte de certaines pages de l'application Potentiel dans le but de mettre davantage en avant les informations utiles à chaque profil d'utilisateur.&#x20;

Dès sa connexion sur Potentiel, l'utilisateur doit pouvoir retrouver rapidement projets en attente d'actions de sa part, les projets modifiés récemment.&#x20;

#### Pages à tester&#x20;

* Page "Vue d'ensemble" : alertes, tableau dernières modifications, tableau derniers projets en cours
* Page "Demandes"
* Page "Projets"

Lien vers le prototype :  [https://www.figma.com/proto/k5KPjBsg1bzdR9PRrj0J1E/Potentiel?page-id=4%3A8\&node-id=829%3A8590\&viewport=501%2C48%2C0.11\&scaling=scale-down\&starting-point-node-id=829%3A8590\&show-proto-sidebar=1](https://www.figma.com/proto/k5KPjBsg1bzdR9PRrj0J1E/Potentiel?page-id=4%3A8\&node-id=829%3A8590\&viewport=501%2C48%2C0.11\&scaling=scale-down\&starting-point-node-id=829%3A8590\&show-proto-sidebar=1)

#### Nos points d'incertitude &#x20;

* Position du menu
* Position de la barre de recherche sur chaque page&#x20;
* Page demandes : choix des filtres proposés
* Page demandes : visibilité du bandeau "demandes archivées" en bas de page
* Page projets : choix des filtres proposés&#x20;
* Page projets : visibilité de l'option "télécharger les attestations"
* Page projets : absence de l'option de partage de projets à d'autres utilisateurs (déplacé dans "mon compte")

### Déroulé du test&#x20;

Consigne : l'utilisateur devra exprimer à haute voix tout ce qui lui passe par la tête durant tout le test : ce qu’il voit, ce qui attire son regard, ce qu’il recherche, ce qu’il s’apprête à faire, ce qu’il ressent (fonctionnalités, design appréciés, frustration, incompréhension, etc.).

<mark style="color:yellow;">PARTIE 1 : SCÉNARIOS</mark>

**Test 1 : Télécharger une attestation de désignation** \
Scénario : “Après une notification (par email) vous souhaitez télécharger un courrier de désignation” \
Succès : le porteur recherche un projet depuis la page “projets” en utilisant les filtres / champ de recherche

**Test 2 : Télécharger plusieurs attestations de désignation** \
Scénario : “Après une notification (par email) vous souhaitez télécharger plusieurs courriers de désignation d’un coup” \
Succès : le porteur se rend sur la page “projets” et coche les projets pour afficher le bouton “télécharger l’attestation”

**Test 3 : Modification de projet** \
Scénario : “Vous souhaitez modifier un projet (ex : changement de puissance)” \
Succès : le porteur va sur la page “projets” et utilise la recherche et/ou les filtres sur la liste de projets pour retrouver son projet

**Test 4 : Invitation sur un projet** \
Scénario : “Vous souhaitez inviter un collègue sur un projet” \
Succès : par lui même le porteur choisit d’aller dans “mon compte” pour rechercher cette fonctionnalité (la page n’est pas maquettée)

<mark style="color:yellow;">PARTIE 2 : ECHANGE LIBRE</mark>

* La page est-elle utile ?
* La pages est-elle lisible ?
* Trouve-t-on facilement les informations recherchées ?
