# 🎽 Lancement de sprint

Pour le lancement d'un sprint, dans Gitbook :&#x20;

* [ ] Créer la page du sprint dans Gitbook en dupliquant la [page modèle](sprint-23-4-mars-au-15-mars.md)
* [ ] Mettre à jour les informations sur le sprint lors du lancement avec l'équipe (objectif, support, vacances, les parties "rétrospective" et "démo" sont remplies en cours de sprint)
* [ ] Déplacer le sprint qui s'est terminé dans "[Précédents sprints](precedents-sprints/)" sous le trimestre en cours

Pour le lancement d'un sprint, dans Airtable :&#x20;

* [ ] Si le sprint n'existe pas dans Airtable dans la [table sprints](https://airtable.com/apphLwfLi4vad9EAq/tblssLQQyknwcNgeV/viwGpob01rBMW771V?blocks=hide), l'ajouter (nom, dates, statut "En cours", trimestre en cours, lien vers la page du sprint créé dans Gitbook)
* [ ] Si le sprint existe dans Airtable dans la [table sprints](https://airtable.com/apphLwfLi4vad9EAq/tblssLQQyknwcNgeV/viwGpob01rBMW771V?blocks=hide), modifier son statut vers "En cours" et ajouter le lien vers la page du sprint créé dans Gitbook dans "Page Gitbook"
* [ ] Dans la [table backlogs](https://airtable.com/apphLwfLi4vad9EAq/tbl8Xmi9jiTVtLxVp/viwRTdGHbUvLmTPlZ?blocks=hide), pour les 2 vues "Sprint en cours" et "Sprint Kanban", modifier le filtre sur le sprint avec le nouveau sprint.

<figure><img src="../.gitbook/assets/image (24).png" alt=""><figcaption></figcaption></figure>

* [ ] Dans la [table backlogs](https://airtable.com/apphLwfLi4vad9EAq/tbl8Xmi9jiTVtLxVp/viwRTdGHbUvLmTPlZ?blocks=hide), pour les 2 vues "Sprint+1" et "Sprint+1 Kanban", modifier le filtre sur le sprint avec le sprint suivant.

Communiquer sur le lancement d'un sprint dans Mattermost :&#x20;

* [ ] Partage un message en reprenant les informations principales du sprint dans Gitbook dans le canal startup-potentiel, exemple :&#x20;

**\[🏃Début du sprint 8 du 10 juillet au 21 juillet]**

Hello, \
Nous avons lancé ce matin le premier sprint pour Q3.&#x20;

Les vues des sprints dans Airtable ont été mises à jour.

🎯 L'objectif de ce sprint est de concevoir le parcours complet souhaité pour la gestion des garanties financières et de leur renouvellement (atelier de conception ce mercredi à 10h)

⛑️ Support : Hubert pour ce sprint

🏝️ Vacances : Sylvain sera absent le jeudi 13 juillet
