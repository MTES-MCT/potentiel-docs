# 📬 Notifications ✅

Les templates des mails sont sous Mailjet : [https://app.mailjet.com/](https://app.mailjet.com/)\
Les templates de mail Mailjet non utilisés par Potentiel sont précédés de la mention "\[Template Non Utilisé]".

Les objets des templates des mails ne sont pas pris dans Mailjet mais sont définis dans le code car on y injecte des variables.

Exemples pour le délai CDC 2022 l'objet du mail est :

`Potentiel - Nouveau délai appliqué pour le projet ${projet.nomProjet}`

Et pour demande validée c'est : `Potentiel - Nouvelle information de type ${type} enregistrée dans votre département ${project.departementProjet}`<br>
