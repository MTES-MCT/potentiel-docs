# 🔗 Raccordement ✅

## 🎯 Objectifs

* [x] Un porteur de projet peut déclarer son gestionnaire de réseau et saisir un ou plusieurs identifiants de dossier de raccordement.
* [x] Un administrateur peut ajouter des gestionnaires de réseau dans Potentiel (avec le format attendu pour l'identifiant de dossier de raccordement)
* [x] Un administrateur peut importer des données de raccordement pour tous les gestionnaires de réseau.
* [x] Refonte complète du domaine Raccordement

## 📆 Planning

* Fonctionnalité finalisée et déployée en Production en juin 2023
