# Importer des candidats pour désignation \[ARCHIVE]

### Paramètres du fichier csv attendu

A l'enregistrement du fichier csv, voici les paramètres à sélectionner :&#x20;

* séparateur : point-virgule
* encodage : Windows 1252

### Contenu des colonnes attendu

A l'import du fichier de candidats d'une période, certaines données font l'objet d'une validation et seront renommées dans la table "projects", tandis que les autres sont stockées dans la colonne "details" de la table "projects".

**Dans le tableau ci-dessous nous décrivons seulement les données faisant l'objet d'une validation** (cela ne veut pas dire que les autres colonnes ne doivent pas être complétées).

_Description des colonnes :_&#x20;

* _colonne import : intitulé de la colonne du fichier importé_
* _donnée attendue : type de donnée ou valeurs attendues_
* _donnée requise_&#x20;
* _colonne table "projects" : nom de la colonne correspondante dans la table `project` dans Potentiel_
