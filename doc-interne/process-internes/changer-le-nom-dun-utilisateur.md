# Changer le nom d'un utilisateur

:warning: Attention, pour le moment ce ne peut être fait que par des développeurs

* Changer directement le nom (fullName) dans la table `Users` en production
* Se connecter à l'espace admin de [keycloak](https://auth.potentiel.beta.gouv.fr/) (variable de connection dans scalingo) et changer le nom ici également
