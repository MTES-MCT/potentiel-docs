# 🛫 Onboarding

Bienvenue dans l'équipe Potentiel 🥳, ci-après un aperçu de ce qui t'attend pour tes 1er jours.

### **Si tu es nouveau dans la communauté Beta Gouv :**&#x20;

* [ ] T'inscrire sur beta.gouv et créer ta fiche membre ([Le 1er jour chez Beta Gouv](https://doc.incubateur.net/communaute/travailler-a-beta-gouv/bienvenue/premier-pas-indispensable-creer-ta-fiche-membre))
* [ ] Accéder à Mattermost (rajouter le lien vers la doc)&#x20;
* [ ] Rejoindre les canaux Mattermost selon ton profil (dev : domain-dev, ux, etc.)
* [ ] T'inscrire à une session d'embarquement beta.gouv [par ici](https://doc.incubateur.net/communaute/travailler-a-beta-gouv/bienvenue/premier-pas-indispensable-creer-ta-fiche-membre) (le premier lundi de chaque mois de 14h à 15h30)&#x20;
* [ ] Si tu es développeur : t'inscrire à une session d'embarquement dev[ par ici](https://airtable.com/shrUCbUT72KtKefsu) (la prochaine a lieu le ... à 14h)
* [ ] Transmettre infos sur le fonctionnement avec Malt (orga CRA, etc.)&#x20;
* [ ] [Les 1ères semaines chez Beta Gouv](https://doc.incubateur.net/communaute/travailler-a-beta-gouv/bienvenue/to-do-darrivee)



### **Embarquement dans l'équipe :**&#x20;

* [ ] Te présenter les rôles et responsabilités dans l'équipe&#x20;
* [ ] Te présenter l'organisation de l'équipe et ses rituels
* [ ] T'inviter aux différents points de l'équipe dans l'agenda&#x20;
* [ ] 30 min avec chaque membre de l'équipe - apprendre à se connaitre, poser des questions
* [ ] Ajouter ton mail (beta ou autre) aux mail team@potentiel.beta.gouv.fr ([https://admin.alwaysdata.com](https://admin.alwaysdata.com/) : email > liste de diffusion > utilisateur : ajouter > aller sur la plateforme Postorius > team@potentiel.beta.gouv.fr > Opérations groupées > Abonnements en masse)&#x20;
* [ ] [Mettre à jour la page L'équipe](../../) avec les infos te concernant : mail, téléphone, disponibilités...&#x20;
* [ ] Lire la documentation, tout est dans Gitbook : [équipe](../../), [outils](../../outils.md), [organisation](../organisation/)
* [ ] Nous faire un rapport d'étonnement suite à tes 1ères semaines dans l'équipe (dev, orga, métier)
